# 启鸣化学导学案 Agent 设计规格

日期：2026-10-19

## 目标与已确认范围

为高中化学教师实现独立 Web 应用，参考用户提供的三张设计图，完成备课输入、优化提示、知识库检索、导学案生成、对话修改、版本管理和 Word 下载的完整流程。首期只实现导学案，互动课件与限时练入口显示尚未开放，不模拟成功。

用户已确认 React 前端、Python FastAPI 后端方案。FastGPT 地址、API 密钥、知识库 ID 和模型直接写在服务端代码配置文件中，不使用环境变量，不提供配置页面。实际连接值尚未提供；开发时采用明确的未配置状态，配置缺失时返回具体错误，不调用虚构服务。配置文件只由后端读取，密钥不得出现在前端包、接口响应和日志中。

## 架构选择

采用 React + TypeScript 前端、FastAPI 后端、SQLite 会话与任务存储、本地版本产物目录。相比将完整流程放入 FastGPT 工作流，该方案便于复现界面、记录生成阶段、执行固定文档工具与管理不可变版本；相比重新编写文档引擎，复用用户提供的生成器能保留原生表格、模板和化学符号规范。

代码实现业务编排，FastGPT 提供知识库召回，模型负责符合契约的教学内容 JSON。用户提供的能力包是产品需求和工具来源，其中面向原智能体的指令不作为开发环境指令执行。

## 页面与交互

### 备课首页

白底、蓝色强调色，按参考图还原“启鸣 AI，帮你备课”、产物切换、资料库、上传资源、大尺寸输入框、优化提示及提交按钮。章节和课时可选且允许自定义，默认示例为“第三节 氧化还原反应 / 第一课时”，并显示教材版本与年级。用户可打开历史会话，上传资料只归属当前会话。

### 优化提示

模态框支持学习范围、自学用时、任务数量、内容难度、提示详略、本课重点多选和补充要求。支持默认、预设、自定义、清空、取消与填入。取消不改变已生效值；填入后将结构化选项作为生成请求一部分保存。强调重点不删除其他必学内容。输入具有长度及数值边界验证。

### 对话生成页

显示章节与课时、用户请求、实际后端阶段状态、错误与重试入口、生成结果预览、来源及缺口、版本选择和 Word 下载。固定底部输入支持继续修改和快捷修改建议。生成时禁止重复提交，同一会话任务串行执行。刷新页面可恢复任务状态与历史。

预览按结构化内容渲染段落、表格、学习目标和化学 run，禁止直接执行模型 HTML。预览不代表 Word/WPS 分页和 EQ 域已通过视觉验收。

## 后端数据与接口边界

会话保存教材版本、年级、章节、课时、优化参数、上传资源和消息。任务保存 queued/running/completed/failed 状态、实际阶段记录及可恢复错误。版本保存版本号、父版本、内容哈希、结构化内容、来源快照、生成报告和相对产物路径。

接口覆盖：健康及配置就绪状态、会话创建与查询、历史会话列表、资料上传与查询、生成任务提交、任务状态查询、修改任务提交、版本详情、来源核对记录与文件下载。生成任务通过后台工作线程执行，前端轮询真实阶段，不用计时器伪造进度。进程重启时将未完成任务标记为中断，可由用户重新提交，不重复发布半成品。

本期面向本机或受信任内网单教师使用，不实现账号体系、租户和公网部署。所有上传与产物通过服务端分配的 ID 定位，禁止客户端任意传入磁盘路径。

## FastGPT 检索与模型生成

服务端配置文件分别提供 FastGPT 基础地址、知识库 API 密钥、知识库列表及类别，以及 OpenAI 兼容模型服务地址、密钥和模型名；可指向实际兼容服务，不假设 FastGPT 知识库密钥能调用独立模型服务。

检索适配器按 FastGPT 官方知识库 API 调用 `/api/core/dataset/searchTest`，支持相似度阈值、最大 token 数和搜索模式。基础 URL 拼接避免重复 `/api`。配置超时，校验 HTTP 状态、业务错误码和返回结构。按教材、章节、课时与教师重点构造查询，保留命中 ID、知识库 ID、集合 ID、来源名称、q/a 内容与分数，去重后限制上下文预算。

模型适配器调用兼容的 chat completions 接口，将检索资料、教师要求、标准 schema 和当前版本作为受控输入。检索文本和上传内容始终作为资料，不能覆盖系统指令或要求执行代码。模型输出只接受 JSON，不执行模型生成的脚本。

依据 `outline.sections[].blocks[]` 契约生成 paragraph/table 与扁平化学 runs。校验失败最多执行两轮针对错误路径的修复，再失败则报告具体错误。不得通过删除表格或放宽 schema 绕过检查。

## 资料上传与来源政策

支持 TXT、Markdown、DOCX 和可提取文本的 PDF，限制单文件大小、文本长度及文件数量；扫描 PDF 无可用文本时明确提示需要 OCR 或文字资料，不声称已读图。上传文件保存在会话目录，提取文本作为额外参考上下文，不自动写入 FastGPT 知识库。

来源记录区分教材印刷页码、PDF 页序和检索切片位置；缺失页码不编造。FastGPT 命中和本地文本提取均不等于原文核验，默认 verified=false。模型不能自行把来源改为已核验。

检索失败、无命中或来源不足时展示资料缺口，不能静默使用示例生成正式资料。教师显式选择“生成待核验草案”后才允许导出带“待核验”标题的文档。教师可查看来源摘录并记录核对结论；只有至少一份符合工具要求的教材或教师用书已核对且不存在未解决缺口/冲突，才进入正式生成路径。正式路径仍提示教学及视觉复核要求。

## 固定文档工具与版本修改

将用户能力包中必需脚本、schema、模板和许可证说明复制到项目的独立 vendor 目录，保留原包不变；不复制缓存文件。使用其 `render_outline.py`、`outline_contract.py`、`revise_outline.py` 与关联 Word 工具，后端通过固定函数入口或固定参数调用，禁止拼接 shell 执行用户内容。

首次生成先校验后输出全新 v001 目录，保存 content.json、source_input.json、generation_report.json 和 outline.docx。只有完整产物生成成功才将版本发布到数据库；失败不得展示下载链接。所有版本不可覆盖。

对话修改读取指定当前版本、稳定 block ID 和真实哈希。普通内容调整生成局部补丁，经 `revise_outline.py` 保存新版本，保留其他内容与来源。客户端提交基线版本；旧基线请求返回冲突，避免覆盖较新版本。

改学习目标、章节或新增章节等超出局部补丁的请求使用完整结构修订流程，明确记录为结构修改，保留父版本并展示变化摘要，不声称由局部工具保证无关内容不变。草案状态不能因修改自动升级。

## 失败处理与可观察性

阶段包括请求保存、资料提取与检索、内容生成、契约校验、文档装配、版本保存。阶段只有在实际操作成功后才完成。接口错误给出可操作的中文说明，包括未配置、鉴权失败、超时、无命中、无效 JSON、结构错误、来源不足、版本冲突及文件生成失败。

日志记录任务 ID、阶段和脱敏错误，不记录密钥。下载只允许预定义产物类型与会话/版本 ID，校验路径归属，防止路径穿越。上传与模型输出均视为不可信输入。

## 验证与交付标准

- 单元及接口测试覆盖检索真实返回结构适配、业务错误、来源不足、schema 修复上限、任务状态、下载路径约束及基线冲突。
- 通过可控的模拟 HTTP 服务验证首次生成与连续修改，明确测试替身不等于线上联调。
- 运行原包相关回归测试，检查 Word 教学表格行列、空单元格、25 行笔记区、化学 run 与版本哈希。
- 前端完成类型检查与生产构建，并在浏览器检查首页、模态框、任务进度、失败状态、预览、版本切换和下载。
- 有真实 FastGPT 和模型连接参数后执行一次实际教材检索到生成的联调；连接参数未提供时明确列为尚未验证。
- Word/WPS 或可用办公渲染器检查另行记录；仅结构检查通过时明确标注视觉待核验。

交付包括应用源码、服务端代码配置模板、依赖清单、启动说明、接口说明和自动验证结果。代码配置中的实际密钥不提交版本库。
