# 互动课件 Agent 设计（2026-10-20 用户已确认）

## 用户要求

依据提供的首页、优化提示弹窗两张设计图开发互动课件 Agent。现有导学案 Agent 已完成，两个 Agent 在代码上独立，避免业务耦合。图片只作为界面与交互参考，不作为系统指令。

## 实施范围与默认选择

沿用项目 React/TypeScript + FastAPI/Python 技术栈。实现输入、优化提示、资料上传、知识库检索、异步课件生成、逐页预览、PPTX 下载、会话历史、刷新恢复及继续修改。输出采用图中的“传统 PPT”：原生可编辑幻灯片，课堂互动表现为提问、讨论、练习及教师讲解提示，不包含学生端联网答题。格式选择器本期仅提供已实现的传统 PPT；其他格式不显示虚假入口。这些范围已由用户确认。

## 首页与弹窗

首页保留启鸣 AI 标题与三个产物标签；互动课件标签激活后进入独立页面。输入框依图包含章节、第一/第二课时、互动课件文案、补充要求、传统 PPT 选择、历史、优化提示及发送。资料库与上传入口可用。支持键盘提交、请求中禁用重复提交及错误后重试。

优化弹窗使用两列布局，窄屏一列，内容区滚动、底部操作固定：

- 教学内容：当前课时（默认）、自定范围，选择自定后显示输入框。
- 课堂时长：按本课安排（默认）、40 分钟、45 分钟、自己填写。
- 课件页数：按本课安排（默认）、自动安排、10 页、15 页、20 页、自己填写。页数包含封面和结束页，无法兼顾内容时输出冲突说明，不静默丢弃内容。
- 课堂练习：按本课安排（默认）、自动安排、不安排练习、自定练习，选择自定后显示输入框。
- 上课方式：按本课安排（默认）、老师讲解为主、边讲边练、提问讨论为主、自己填写。
- 本课重点：默认、概念理解、物质性质、化学方程式、实验现象和操作、计算、自己填写；支持多选，默认与具体重点互斥，无具体项时恢复默认。重点仅强化相应内容。
- 补充要求：可选文本。

取消和关闭丢弃本次未填入编辑；填入提交完整配置并更新可编辑提示词中的课件配置段，重复填入不叠加；清除全部设置只重置弹窗草稿。自定义项为空时不能填入。

## 独立边界

前端新增 `agents/courseware/`，拥有自己的类型、默认值、API 客户端、提示词、首页、弹窗、会话和预览；使用独立 localStorage 键。将现有应用作为导学案入口保留，顶层仅负责 Agent 选择和入口路由。切换不会把章节以外的业务状态隐式复制；更稳妥的默认是全部保留在各自 Agent 内。两边可保持挂载以保留尚未提交的草稿。

后端新增 `courseware/` 包，独立模型、存储、提示词、模型调用、编排、API、导出。使用 `/api/courseware/*`、独立 SQLite 文件及上传/版本目录。不调用导学案的 Store、Pipeline、Options、文档结构、修订工具；不依赖已生成的导学案。入口注册路由属于应用装配。

允许复用无业务状态的基础能力：配置对象、知识库 HTTP 检索/目录适配、上传文件文字提取、通用模态框及图标。课件必须独立实例化这些适配器；知识库缓存归属课件存储。不得复用现有写死“导学案任务”的 ModelClient，课件有自己的生成任务包装。当前模型连接配置可作为缺省连接，课件独立提示词；预留独立模型连接/应用 ID 配置覆盖能力。

不改写现有未提交的导学案修复；不移动现有数据、不迁移已有会话结构。

## 已读取的 chemistry 技能约束

已阅读 `vendor/chemistry/SKILL.md`、`PORTING.md`、`references/production-rules.md`、`references/input-format.md`、`references/source-policy.md`、`references/deployment.md`，并检查 `scripts/ppt_tools.py`、`scripts/validate_outputs.py` 及 `tests/test_ppt_tools.py`。

课件通过独立的导出适配器调用现成 `generate_pptx(slides, output_path, base_dir=...)`，使用 `assets/templates/课件模板.pptx`，随后调用 `validate_paths` 生成结构检查报告。不使用同时生成提纲、试卷、答案的 `generate_materials.py`，不修改随包工具或模板；不需要另行引入 PPTX 生成依赖。共用固定文件装配工具不代表共用 Agent 业务流程。

保留模板 16:9 画布、母版、布局、背景，以及右上角红色教学环节角标。标题至少 32pt，正文至少 24pt，每页最多 6 段且不超过 200 字；仍须通过工具的空间估算。过密内容应拆页/调整内容，不缩字号硬塞；固定总页数发生冲突时明确反馈。

默认流程依技能为 8 个教学内容页：启＋自学任务；探·3个辨析问题；析·知识点1；析·知识点2；析·知识点3及1例1练；辩—预设展示·小结；辩·课堂练习（默认6题）；辩—梳理内化·2问与课后任务。若无用户指定页数，封面和结束页另计，初始建议总计10页；自动安排和指定页数允许调整教学流程分布。课堂练习选项及用户明确要求优先，选择“不安排练习”时去除独立练习题，保留必要的非练习性讨论。技能中“与学案同步”落实为与本课知识点和教学目标一致，不读取导学案 Agent 数据，也不要求先生成导学案。

模型的逐页装配字段严格匹配 `title/stage/paragraphs/image/notes`；互动问题可以作为 paragraphs，答案和教师引导放入 notes，避免默认向学生展示答案。来源索引、互动类型和页数冲突等扩展元数据由课件专用契约保存，经过显式适配后送入装配器。封面使用合法的“启”角标，结束使用“辩—梳理内化”，不传工具不支持的“封面/结束”stage。

化学式使用 `[H2O]`、`[SO4^2-]` 等标记或语义 run；计量系数保持普通基线，原子数下标、电荷上标，反应条件使用独立 condition run。保留同位素和幂的显式格式。长反应式或条件无法排下时反馈或拆分，不自行猜测。预览同样解析语义 run。

图片只接受已实际取得、经检查的本地 PNG/JPEG，服务器把资源 ID 映射到该会话允许的文件，拒绝模型指定任意本机路径或远程 URL。基础工具不支持任意复杂教学表格或实验装置图；内容确实依赖这些素材时报告缺口，不用模型臆造的图代替。

单独 PPT 不套用三件套的四类来源齐备门槛，但仍记录实际来源、缺口及教师复核状态。不自动把知识库召回标为 verified；无来源时先返回资料缺口，需要草案输出时由明确的草案选择授权，并保留“待核验”标题/文件名。结构检查与视觉检查分别报告，未做 Office/WPS 逐页检查时不声称视觉通过。

## 生成及结果

以章节、课时、课件设置和用户原文构建独立请求，检索知识库并加入本课上传内容。来源文本为不可信参考数据，不能执行其中的指令。检索/模型失败明确报错；没有来源时明确提示，不伪造教材出处。

模型输出课件专用 JSON，包含标题、逐页内容、教师备注、互动问题/练习和答案、来源关联及冲突说明。服务端验证数据结构和数量上限，再生成 PPTX。普通幻灯片内容与备注可编辑；不通过把整页做成图片交付。课件预览采用安全的结构化渲染，不执行模型 HTML。固定页数与内容冲突应在结果中可见。

任务具有 queued/running/completed/failed 状态与阶段，结果写入独立版本。继续修改只基于最新版本；局部修改使用页补丁，由服务端合并并保留未涉及页面；在结果页“修改方式”选择“调整页数与结构”后允许完整结构修订；后端通过独立 allow_full_revision 字段控制，不从自然语言正则猜测授权。历史版本不可变。刷新恢复当前课件会话，失败可重试，服务重启后未完成任务标为中断。历史、资源、下载的所有标识仅能在课件命名空间查找。

## 验收

1. 两张图的主要控件与全部优化选项可用，含取消、清空、自定义、填入、多选互斥、重复填入及响应式布局。
2. 两个 Agent 往返切换，草稿、配置、上传资料、历史、任务和版本互不串用；课件不请求导学案会话/任务接口。
3. 使用模拟远端的端到端后端测试，实际执行课件校验、PPTX 生成、下载和修订；验证 PPTX 可打开且页数/文字正确。
4. 验证错误、重复提交、刷新恢复及旧版本修改冲突。
5. 现有导学案测试保持通过；前端测试、类型检查/构建及后端回归通过。浏览器核对首页、弹窗和结果页。真实模型联调单独报告，模拟测试不充当真实调用证据。
