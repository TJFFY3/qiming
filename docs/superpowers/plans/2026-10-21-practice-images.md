# 限时练习原图支持实施计划

目标：复用导学案的知识库原图能力，使限时练习在题干、选项、答案和解析中引用、预览及导出图片。

实现约定：题目新增可选 images 列表，每项包含 image_id、caption、placement；placement 为 stem、option_A 至 option_D、answer、explanation。模型只能引用来源目录中的图片，并关联该题 source_ids。普通旧题无需新增字段。

- [x] 图片契约与校验：复用原图下载和校验逻辑，新增题目图片字段、来源与位置校验；已运行并修复失败测试。
- [x] 生成与交付：向模型提供不含 URL 的图片目录；生成和修订保存原图快照；两份 Word 嵌图；提供按版本取图接口；历史下载复用快照离线重建。
- [x] 前端与验证：题干、选项和解析按位置显示图片及图注，失败保留图注并提示；已验证学生卷不泄漏解析图、旧版本兼容及端到端图片链路。

沿用现有工作目录，以保留尚未提交的导学案图片实现；不修改原始资料或既有版本。实现与验证均在当前会话完成。

实施记录：原图公共能力在并行工作中已抽至 source_images，限时练习直接复用该中性模块。已用知识库“丁达尔效应对比实验”原图验证页面展示及两份 Word 嵌图；独立代码审查未发现重要问题。模板图片不作为题源发送给模型。
